# 📬 Mail.tm Web Client

一个基于 [Mail.tm](https://mail.tm) 免费临时邮箱 API 的纯前端 Web 应用。
只用 HTML + CSS + 原生 JavaScript 套壳实现，无需后端、无需构建、无需 API key。

> ⚠️ 本应用依赖 Mail.tm 公共服务可用性；邮箱仅用于临时接收验证邮件，
> **切勿用于重要账号、金融业务或敏感通信**。

---

## ✨ 功能特性

- 🪄 一键生成临时邮箱地址（自动从可用域名中挑选）
- 📥 实时收件箱（定时轮询，可手动刷新）
- 📖 查看邮件全文（支持 HTML 正文）
- 🗑️ 删除邮件 / 丢弃当前邮箱并重新生成
- 📋 一键复制邮箱地址到剪贴板
- 💾 会话保持：邮箱与 token 存入 `localStorage`，刷新页面不丢失
- 🌙 现代化响应式 UI，适配桌面与移动端

## 🛠 技术栈

- HTML5（结构）
- CSS3（样式，可使用 CSS 变量 / Flexbox / Grid）
-原生 JavaScript（ES6+，`fetch`调用 API）
- [Mail.tm API](https://api.mail.tm)作为后端

本项目使用了人工智能辅助制作
